# Diarized-JSON-SRT-Converter
Converts speaker-diarized per-word timed transcription JSON output from ElevenLabs (Scribe v3) and AirCaps (A5S Async v1) into a clean, Subtitle-Edit-friendly `.srt`. Pure Python 3.8+ standard library - no third-party packages are needed at runtime. Feature rich, with dialog-dash and line balancing support.
